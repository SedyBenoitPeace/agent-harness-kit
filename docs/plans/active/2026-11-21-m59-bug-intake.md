## M59-001 Bug kind

`"kind": "bug"` on a feature. status.sh and context.sh show it. A bug
feature needs no brief: its checks are the reported symptom.

## M59-002 Bug intake from GitHub

issues.sh sync: an issue labelled `bug` with no `[id]` title becomes a
failing kind-bug feature with the next id in the bug milestone, and the
issue is retitled `[id] title` (the issue still owns title, decision 6).
Idempotent; fake `gh` fixtures only.

## M59-003 Reproduce before fixing

reported symptom; no fix or hypothesis before it. The PROGRESS entry ends
