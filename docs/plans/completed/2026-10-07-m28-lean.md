# M28: The lean pass

**Goal:** an agent reads as little as possible every session, and the kit
stops carrying things that go stale.

**Why:** the harness should stay lean: every rule is something the model
must read and may misread, and scaffolding should come out as models
improve. M23–M27 grew the protocol from 532 to 592 lines, all of it read
every session, though a session uses about 125 of them. Named models in
`agents/models.json` go stale with every release. The owner agreed: keep
the agents, the mods and the opt-in features; cut what the agent reads
every session and what rots.

## M28-001 — Drop the model names

- Delete `agents/models.json`. Generated agent files carry no model line;
  every CLI uses its own default. Agent sources lose `tier`.
- second-opinion.sh passes no model flag; the model fallback goes.
- The sensitive-path globs that lived in models.json become the words the
  protocol already uses (auth, payments, personal data, migrations).
- README: one line of advice, no model names.

## M28-002 — Split the protocol by when it is read

- `harness-protocol.md` keeps the session core (§2.1–2.6) and an index to
  three files read only when needed:
  `harness-protocol-planning.md` (§1, setup and briefs),
  `harness-protocol-runs.md` (§2.7–2.8, harness-run / harness-continuous),
  `harness-protocol-maintenance.md` (§3, harness-audit).
  Section numbers stay, so every `§` reference still resolves, and
  "harness-protocol.md section 2" prompts keep working.
- Setup, upgrade, audit, the session context check and the mirror sync
  handle all four files.

## M28-003 — Size limits and rule expiry

- Gate: the session core ≤150 lines; AGENTS.md.tmpl ≤70 lines.
- A rule a session adds to AGENTS.md ends with `(added <YYYY-MM-DD>)`, plus
  `; model: <name>` when it fixes one model's failure. harness-audit warns
  on rules added more than 90 days ago: re-test them (drop, run a session
  or two, delete if nothing breaks).

## M28-004 — Drop the next-steps band; release 3.6.0

- Remove the next-steps band mod (the least useful of four); the decision
  register, supervisor and budget guard stay.
- CHANGELOG 3.6.0 with its Upgrade block; manifests 3.6.0; mirror synced.
