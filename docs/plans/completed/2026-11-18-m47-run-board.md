# M47: live run board

**Goal:** while harness-run or harness-continuous runs, a self-refreshing
local page `.harness-run/board.html` shows every feature's stage, agent,
gate and cost for any CLI, opened once automatically, with no extra
assistant tool call per feature.

**Brief (source of truth for every detail below):**
`docs/briefs/2026-11-18-run-board.md`. Read its Deliverables, Non-goals
and Done when before building; this plan only splits it in two.

## M47-001

- `run-start.sh`: writes `.harness-run/run-id`, deletes `board-opened`,
  archives `events.log` with the other logs under `previous/<previous
  run-id>/` (start-commit fallback).
- Event writers (only when `.harness-run/start` exists in the main repo,
  lane worktrees resolved via `git rev-parse --git-common-dir`):
  `dispatch.sh` (`dispatch`, every CLI), `run-gate.sh` (`gate`, id from a
  `lane/<id>` branch else `-`), `second-opinion.sh` (`opinion`),
  `run-start.sh` (`run-start`), `run-report.sh` (`run-end`).
- New `skills/harness-run/scripts/board.sh <target> [--open]`: the page,
  the current-result rule, stage order, gate/time/cost/agent columns,
  header, expandable rows, 5 s reload, `--open` once per run-id with
  `HARNESS_BOARD_OPEN` / `HARNESS_BOARD_OPEN_CMD`.
- New `scripts/test-board.sh`, called from `scripts/e2e.sh`: every brief
  Done-when case that needs only board.sh, run-start.sh and the event
  writers (stages, stale result, ties, archive by run-id, opener counter,
  timing).

## M47-002

- Board refresh as the last step of `dispatch.sh`, `second-opinion.sh`,
  `run-gate.sh`, `context.sh`, `status.sh` (guarded: start exists, last
  event not `run-end`), `run-report.sh` (after `run-end`), and
  `run-start.sh` (`--open`, passes the `BOARD:` line through). Call form:
  `bash "<dir>/board.sh" <target> >/dev/null 2>&1 || true`.
- `skills/harness-run/SKILL.md`: call `run-start.sh` once at start; both
  SKILL.md files put the `BOARD:` line in the first progress line.
- test-board.sh: wiring cases (junk-printing board.sh changes no caller
  output or exit code, no writes without a run, no rewrite after
  `run-end`, final snapshot says `run ended`).
- Docs: `harness-protocol-runs.md` template, README, CHANGELOG; version
  3.21.0 in the seven files the brief lists.
